# script.keymap

魔改版 更新


1.全汉化；


2.新增：视频流、音轨、字幕一键映射（仅 Piers 及以上适用）；


3.新增：视频流、音轨、字幕一键映射（任意版本 kodi/coreelec 的导火线/地平线/清风 2 复活魔改版系列皮肤适用）；


4.新增：OSD 播放列表一键映射（任意版本 kodi/coreelec 的导火线/地平线/清风 2 复活版系列皮肤适用）；


5.新增：剧集跳过片头片尾的"记录当前时间为跳过点 (片头/片尾)"/"删除当前剧集的跳过点记录"映射（任意版本适用）； 
  注意：需要先安装 跳过片头片尾插件： `https://github.com/wabisabi926/plugin.video.skipintro`


6.新增：自定义动作映射功能（v1.6.6）：
   - 支持添加任意 Kodi action 字符串（如 RunScript、ActivateWindow、SetProperty 等）并绑定按键；
   - 支持按环境（全局、全屏视频、首页等）分类管理自定义动作；
   - 支持添加后立即绑定按键，操作流程更流畅；
   - 支持在"自定义动作"类别中查看、删除已添加的自定义动作；
   - 自定义动作数据持久化存储在 `special://profile/addon_data/script.keymap/custom_actions.json`。

# script.keymap
A keymap editor for Kodi（特别适配 plugin.video.filteredmovies 插件版本，需先安装该插件）

**filteredmovies 魔改版特性：

- 新增功能：**“打开筛选/T9 搜索页面” 一键映射；**
- 新增功能：**“倍速播放（coreelec 下不适用）、音频流、字幕流” 一键映射；**
- 新增功能：** “剧集跳过片头片尾的 记录当前时间为跳过点 (片头/片尾)/删除当前剧集的跳过点记录” 一键映射；**
- 新增功能：**“打开当前播放剧集的列表” 一键映射；** 
- 新增功能：**“切换收藏状态/将选中项加入或移出收藏夹” 一键映射；** 
- 新增功能：**“VS10 引擎模式切换” 一键映射；** 
- 新增功能：**“Linux 下重启 Kodi” 一键映射；**
- 新增功能：**“重启到内部存储 (Reboot from eMMC/NAND)” 一键映射；**
